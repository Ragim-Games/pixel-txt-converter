# Pixel TXT Converter 2.0.0 · Windows

1. `PixelTxtConverter.exe`를 실행하고 **설치 / 메뉴 연결**을 누릅니다.
2. 이미지 우클릭 → **TXT Convert**: 같은 폴더에 RGB TXT를 저장하고 메모장으로 엽니다.
3. TXT 우클릭 → **TXT Restore (PNG)**: 이미지로 복원합니다.

Windows 11에서는 **더 많은 옵션** 안에 표시됩니다. Windows 10/11 및 .NET Framework 4.8 환경용입니다. PNG/JPG/JPEG/JFIF/BMP/GIF/TIF/TIFF/ICO를 지원합니다.

RGB는 왼쪽 위부터 오른쪽으로, 다음 행 순서로 `R,G,B/R,G,B/...` 형태로 기록됩니다. 첫 줄에 크기를 저장합니다. 투명 영역은 흰색 배경과 합성합니다. 원본과 기존 출력 파일을 덮어쓰지 않습니다.

설치는 현재 사용자에만 적용됩니다. 실행 파일은 `%LOCALAPPDATA%\PixelTxtConverter`에 복사됩니다. 설치 화면에서 메뉴 연결을 해제할 수 있습니다. EXE는 코드 서명되지 않은 빌드입니다.
