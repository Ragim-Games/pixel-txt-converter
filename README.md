# Pixel TXT Converter

이미지의 모든 픽셀을 **왼쪽 위부터 오른쪽으로**, 행이 끝나면 **다음 행의 왼쪽부터** 읽어 RGB TXT로 저장합니다. 저장한 TXT를 다시 불러와 이미지로 복원할 수 있습니다.

## 실행

이 저장소를 내려받아 **`index.html`을 브라우저에서 여세요.** 설치, 빌드, 서버, 계정이 필요 없습니다. Chrome 또는 Edge 등 최신 브라우저에서 사용할 수 있으며, 모든 처리는 기기 안에서 이루어집니다. 외부 라이브러리, 폰트, 네트워크 요청을 사용하지 않습니다.

1. **이미지 → TXT**에서 이미지를 선택하거나 끌어 놓습니다.
2. 미리보기를 확인하고 **TXT 다운로드**를 누릅니다.
3. **TXT → 이미지**에서 저장한 TXT를 불러옵니다.
4. **PNG 이미지 다운로드**로 복원된 이미지를 저장합니다.

미리보기의 픽셀을 클릭하면 0부터 시작하는 X/Y 좌표, 1부터 시작하는 픽셀 순번 및 RGB 값을 확인할 수 있습니다. **샘플 이미지로 시작하기**로 즉시 체험할 수도 있습니다.

## TXT 형식 (버전 1)

```text
PIXELTXT/1/2/2
255,0,0/0,255,0/0,0,255/255,255,255
```

- 첫 줄: `PIXELTXT/버전/가로/세로`. 이미지 복원에 필요한 크기를 기록합니다.
- 두 번째 줄: 각 픽셀을 `R,G,B`로 기록하고 **픽셀의 RGB 묶음 사이를 `/`로 구분**합니다. 끝에 `/`를 붙이지 않습니다.
- 각 채널은 `0`~`255` 범위의 정수입니다.
- 위 예시는 첫 행이 빨강·초록, 둘째 행이 파랑·흰색인 2 × 2 이미지입니다.
- 데이터의 `n`번째 픽셀(0부터 시작)은 `x = n % 가로`, `y = floor(n / 가로)`에 배치됩니다.
- UTF-8 TXT를 저장합니다. 불러올 때 UTF-8 BOM, CRLF 줄바꿈, RGB 묶음 앞뒤의 공백도 허용합니다.

## 처리 범위

- PNG, JPEG, WebP 등 브라우저가 디코딩할 수 있는 이미지 형식을 지원합니다. 애니메이션 전체나 원본 파일 메타데이터는 보존하지 않습니다.
- 원본 해상도를 유지하며 자동 축소하지 않습니다. 최대 **4,194,304픽셀**, 한 변은 최대 **16,384픽셀**, 입력 파일은 최대 **64 MiB**입니다.
- RGB는 알파 채널을 포함하지 않습니다. **투명도는 흰색 배경과 합성**한 뒤 기록됩니다. TXT에서 복원되는 이미지는 불투명합니다.
- 브라우저에서 디코딩된 RGB 값을 저장합니다. 원본 압축 파일 자체를 복원하거나 색상 프로파일을 보존하는 형식이 아닙니다.
- 잘못된 헤더, 크기, 채널 범위, 누락 또는 초과한 픽셀은 오류로 안내하며 이전 변환 결과를 유지합니다.
- 큰 이미지의 TXT는 원본 압축 이미지보다 훨씬 커질 수 있습니다. 변환을 작은 단위로 나눠 실행하고 진행률을 표시합니다.

## 개발 및 검증

런타임 의존성은 없습니다. Node.js 18 이상에서 핵심 변환 테스트를 실행합니다.

```sh
npm test
```

브라우저 통합 테스트는 선택 사항입니다.

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser.cjs
```

테스트는 픽셀 순서와 RGB 왕복 일치, 투명도, 여러 처리 묶음에 걸친 데이터, 잘못된 TXT, 실제 파일 입력과 다운로드, 모바일 가로 넘침을 검증합니다. 브라우저 테스트 스크린샷은 Git에서 제외된 `artifacts/`에 생성됩니다.

| 파일 | 역할 |
| --- | --- |
| `index.html`, `styles.css` | 한국어 인터페이스와 반응형 디자인 |
| `codec.js` | 크기 검증, RGB TXT 인코딩 및 디코딩 |
| `app.js` | 파일 입출력, 미리보기, 다운로드 및 픽셀 확인 |
| `tests/` | Node.js 단위 테스트 및 브라우저 통합 테스트 |
